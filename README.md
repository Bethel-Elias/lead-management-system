# Lead Management System

Full-stack CRM application built with React and Node.js.

## Features

- JWT Authentication
- Role based authorization
- Lead CRUD
- Lead assignment
- Notes system
- Activity timeline
- Pagination
- Filtering
- Swagger API documentation
- Jest API testing


## Tech Stack

Frontend:
- React
- Bootstrap
- Axios

Backend:
- Node.js
- Express.js
- Sequelize ORM

Database:
- MySQL


## Installation


Clone project

git clone repository-url


Backend:

cd server

npm install

npm run dev


Frontend:

cd client

npm install

npm run dev
